Models · Embed

嵌入向量端点（只读）· 由网关按 model 路由后原样透传
静态说明 · 不发请求
功能介绍 embedding
嵌入（Embedding）把文本映射成定长向量，是语义检索、聚类、去重与 RAG 的基础。llm-hub 提供 Ollama 原生 POST /api/embed 与 OpenAI 兼容 POST /v1/embeddings 两个入口：调用方按 model 选择嵌入模型，网关先做别名解析再路由到对应上游，请求与响应原样透传。嵌入模型与 LLM 共用 upstreams[].models / aliases，未声明的模型不会被路由；OpenAI SDK 等客户端把 baseURL 指向网关即可获得统一的向量服务。
网关把 POST /api/embed（Ollama 原生）与 POST /v1/embeddings（OpenAI 兼容） 原样透传给 model 解析到的上游；模型须在 config.yaml 中声明，否则 404。

Models · Rerank

Rerank 配置（只读）
最后更新 10:17:24
功能介绍 rerank
重排（Rerank）在初步召回之后，用模型对候选文档逐条打分并重新排序，提升问答、搜索与 RAG 的命中质量。llm-hub 暴露 POST /v1/rerank：传入 query 与 documents，网关把请求转换成生成式重排模型可执行的形式，按对数概率打分并归一化为 results[].relevance_score，可用 top_n 与 return_documents 控制输出。

Models · SystemOne

SystemOne 配置（只读）
最后更新 10:17:24
功能介绍 decision
System One 是面向「快速决策」的判定 API：输入一段状态与若干问题，模型直接给出选项、是/否概率或分数，适合意图识别、路由分流、风控与表单校验等低延迟场景。llm-hub 的 POST /v1/systemone 原样透传请求与响应，只负责调用方鉴权和上游签名，因此既兼容 laya-server 的 noul / choice / score 决策契约，也可以直接指向 Ollama 0.40+ 的同名端点与本地模型；请求可用 model 指定后端模型，缺省时按配置注入，stream: true 时后端以 SSE 逐条回带判定结果。

功能介绍 web search
Web 搜索把关键词检索接入大模型应用：POST /v1/tools/web-search 接收查询词，由后台的 opencode-port 抓取匹配网页，返回标题、链接、摘要与正文段落，为问答、摘要与 RAG 提供最新的外部知识。请求体原样转发，仅 query 必填；top_k、locale、recency 控制检索范围与时效，include_sources 附带来源列表，synthesize: true 时额外由模型综合生成答案。检索既可以作为独立工具调用，也可以把返回的 text 直接拼进 prompt。

About

关于 llm-hub · 项目简介、主要功能与版本信息
最后更新 10:17:24
项目简介 overview
llm-hub 是一个 FastAPI 编写的轻量级大模型网关：把多台 Ollama 实例、LM Studio 与 OpenAI 兼容服务收敛成一个统一的 API 入口，按模型名路由、合并别名与参数注入，并原样透传流式响应。在此之上它自己实现了 Rerank、System One 决策与 Web 搜索等扩展接口，附带只读 Web 管理台与 SQLite 请求明细，适合个人与团队把散落的模型实例整理成一套稳定、可观测、可鉴权的服务。
主要功能 features
⛁
多上游聚合路由
按模型名精确匹配、前缀通配（qwen3:* / opencode/*）、优先级选择与宽松回退
✦
别名与参数注入
model_aliases 给实例里的模型换短名，aliases 派生出带独立固化参数的新模型，num_ctx_overrides 固化上下文长度
◍
嵌入与重排
/api/embed、/v1/embeddings 原样透传；/v1/rerank 支持 logprobs 与 embedding 两种打分
◈
System One 决策
noul / choice / score 判定接口，兼容 laya-server 与 Ollama 0.40+ 后端
◎
Web 搜索
转发到 opencode-port 抓取网页段落与来源，可选由模型综合生成答案
⚿
安全与配额
API Key 只来自环境变量、IP 白名单、方法与路径白名单、限流、请求体上限与安全响应头
▤
请求明细与统计
SQLite 记录耗时 / TTFB / token / 脱敏请求响应，提供 P50·P95·P99 与分布统计
⌂
只读管理台
/admin 下的 Vue 控制台：配置投影、上游探测、请求查询、模型清单与压测
↻
运维友好
配置热重载、流式（NDJSON / SSE）原样透传、单镜像 Docker 部署
