参数类型必填说明

querystring是用于检索排序的查询文本

Authorization: Bearer <API_KEY>
Content-Type: application/json
{ "model": "qwen3-reranker:4b", "query": "什么是向量数据库？", "documents": [ "向量数据库用于存储高维向量并支持近似最近邻检索。", "关系型数据库以二维表结构组织数据。" ], "top_n": 1 }
200application/json

{ "results": [ { "index": 0, "relevance_score": 0.92 }, { "index": 1, "relevance_score": 0.31 } ] }
说明：rerank 由 Ollama 上的 qwen3-reranker 提供打分（logprobs），网关负责协议转换与结果归一化；错误返回见 Requests 页面。

请求 API 格式 /v1/systemone
请求参数 POST /v1/systemone
参数类型必填说明
stateobject是自由结构，承载待判定的上下文（如 message），原样透传给后端
questionsobject是问题 id → 标签化问题；type 决定判定形态
questions[].typestring是noul(是/否概率) · choice(单选标签) · score(≥2 标准打分)
questions[].instructionsstring是该问题的判定指令
questions[].criteriastring[]否choice / score 必填的候选标签
modelstring否路由模型；laya-server 接受 auto / english / multilingual / typed-decisions，Ollama 后端需真实模型名
POST/v1/systemone
Authorization: Bearer <API_KEY>
Content-Type: application/json
{ "state": { "message": "I was charged twice and need a refund today." }, "questions": { "refund": { "type": "noul", "instructions": "Does the customer ask for a refund?" }, "intent": { "type": "choice", "instructions": "Primary intent?", "criteria": [ "refund", "cancel", "other" ] } }, "model": "auto" }
200application/json
透传 · 决策结果由 System One 后端返回
{ "model": "laya-rl-agent", "answers": { "refund": { "type": "noul", "noul": 0.9937, "confidence": 0.9937, "action": { "act_probability": 1.0 } } }, "usage": { "input_tokens": 49, "output_tokens": 0 }, "routing": { "model": "multilingual", "reason": "explicit model" } }
说明：请求体与响应体均原样透传给 System One 后端（laya-server 或 Ollama 0.40+），llm-hub 只用调用方的 API Key 鉴权，并用 api_key_env 指向的密钥签名上游调用；systemone.model 为默认注入模型（local = 不注入）。

请求 API 格式 /v1/tools/web-search
请求参数 POST /v1/tools/web-search
参数类型必填说明
querystring是搜索关键词或自然语言问题（唯一必填字段）
modelstring否Provider 侧模型 id，原样透传；省略时由 Provider 决定，不参与本地 alias 解析
top_kinteger否检索页面数，范围 1–50；省略时取 Provider 默认值
max_chars_per_pageinteger否单页字符预算，超出截断，响应 truncated=true
localestring否地区/语言提示，如 zh-CN
recencystring否时间范围枚举：day / week / month / year
synthesizeboolean否true 时额外返回 answer（由模型综合生成的答案）
include_sourcesboolean否true 时在响应中附带扁平 sources[] URL 列表
POST/v1/tools/web-search
Authorization: Bearer <API_KEY>
Content-Type: application/json
{ "query": "llm-hub 网关 使用教程", "top_k": 5, "locale": "zh-CN", "recency": "month", "synthesize": false }
200application/json
透传 · 状态码与响应体原样返回 Provider 契约
{ "query": "llm-hub 网关 使用教程", "model": "ollama-local/qwen3.5:9b", "engine": "opencode-websearch", "answer": null, "truncated": true, "results": [ { "title": "llm-hub 快速开始", "url": "https://example.com/doc", "snippet": "llm-hub 是统一代理本地模型的网关…", "paragraphs": [ "完整段落文本 …" ] } ], "text": "所有检索段落拼接，可直接塞进 prompt", "sources": [ "https://example.com/doc" ] }
说明：请求体原样转发给 Provider（未知字段保留、不重写），响应体与状态码也原样回传，因此字段以 Provider 契约为准；query 为唯一必填。websearch.enabled=false 返回 404，Provider upstream 缺失返回 503。
