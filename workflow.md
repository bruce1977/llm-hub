## 开发工作流程

### 1. 本地开发流程

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                           本地开发流程                                        │
└─────────────────────────────────────────────────────────────────────────────┘

┌─────────────┐     ┌─────────────┐     ┌─────────────┐     ┌─────────────┐
│  1. 克隆仓库  │────▶│  2. 配置环境  │────▶│  3. 安装依赖  │────▶│  4. 启动服务  │
└─────────────┘     └─────────────┘     └─────────────┘     └─────────────┘
       │                   │                   │                   │
       ▼                   ▼                   ▼                   ▼
  git clone           配置 config.json    pip install -r      uvicorn main:app
                      配置 .env           requirements.txt    --reload
```

**步骤详解：**

1. **克隆仓库**
   ```bash
   git clone https://github.com/your-org/llm-hub.git
   cd llm-hub
   ```

2. **配置环境**
   ```bash
   cp data/example.config.json data/config.json
   cp .example.env .env
   # 编辑 config.json 添加上游实例
   # 编辑 .env 添加 API 密钥
   ```

3. **安装依赖**
   ```bash
   python -m venv .venv
   source .venv/bin/activate  # Linux/Mac
   # 或 .venv\Scripts\activate  # Windows
   pip install -r requirements.txt
   pip install ruff  # 开发工具
   ```

4. **启动服务**
   ```bash
   cd app
   python -m uvicorn main:app --reload --port 8000
   ```

**测试命令：**

```bash
# 运行模拟测试 (无需真实 Ollama)
python tests/smoke_test.py

# 运行 E2E 测试 (需要本地 Ollama)
E2E=1 python tests/smoke_test.py

# 运行演示脚本 (需要本地 Ollama)
python tests/demo.py

# 代码检查
python -m ruff check app/ tests/
python -m ruff format app/ tests/
```

### 3. Docker 部署流程

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                           Docker 部署流程                                     │
└─────────────────────────────────────────────────────────────────────────────┘

┌─────────────┐     ┌─────────────┐     ┌─────────────┐     ┌─────────────┐
│  1. 拉取镜像  │────▶│  2. 配置环境  │────▶│  3. 启动容器  │────▶│  4. 验证服务  │
└─────────────┘     └─────────────┘     └─────────────┘     └─────────────┘
       │                   │                   │                   │
       ▼                   ▼                   ▼                   ▼
  docker pull         配置 config.json    docker run          curl /health
  bruce1977/llm-hub   配置 .env           docker compose      curl /v1/models
                      latest              up -d
```

**部署命令：**

```bash
# 方式一: 从 Docker Hub 拉取 (推荐)
docker pull bruce1977/llm-hub:latest

# 准备配置
mkdir -p data
cp data/example.config.json data/config.json
cp .example.env .env
# 编辑 data/config.json 和 .env

# 启动
docker run -d --name llm-hub \
  -p 8888:8000 \
  -v $(pwd)/data:/data \
  --env-file .env \
  --restart unless-stopped \
  bruce1977/llm-hub:latest

# 方式二: 从源码构建
docker build -t llm-hub:latest .
docker run -d --name llm-hub \
  -p 8888:8000 \
  -v ./data:/data \
  --env-file .env \
  llm-hub:latest

# 验证
curl http://localhost:8888/health
curl http://localhost:8888/v1/models
```

## 常见操作速查

| 操作 | 命令 |
|------|------|
| 启动开发服务器 | `cd app && python -m uvicorn main:app --reload` |
| 运行测试 | `python tests/smoke_test.py` |
| 运行 E2E 测试 | `E2E=1 python tests/smoke_test.py` |
| 代码检查 | `python -m ruff check app/ tests/` |
| 代码格式化 | `python -m ruff format app/ tests/` |
| Docker 构建 | `docker build -t llm-hub:latest .` |
| Docker 运行 | `docker compose up -d` |
| 查看日志 | `docker logs -f llm-hub` |
| 重启容器 | `docker restart llm-hub` |
| 停止容器 | `docker compose down` |
